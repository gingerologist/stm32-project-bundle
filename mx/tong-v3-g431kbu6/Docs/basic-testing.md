# 测试

## 高压电源

固件烧入后会输出高电压；Vpp是正20V左右，Vss是负20V左右。



## Instrumentation

命令的设计不是很直觉。

使用如下测试命令，51对应单个通道电流10mA（9.96mA，详见用户手册）。；脉冲宽度200us；周期100ms，即频率是

```
set 51 200 100
start
```



测试项：

| 网络名称      | 测试点标识 | 信号类型 | 说明                                 | 结果                                    |
| ------------- | ---------- | -------- | ------------------------------------ | --------------------------------------- |
| CH0_SD,CH1_SD | C0/C1      | 数字     | OPA2991使能，低电平有效              | 3.3V电平负脉冲，宽度2ms（是不是太多？） |
| R11和Q9A射极  | FB         | 模拟     | VPP和FB之间的压降是R11的电流*100欧姆 | 设置为51/10mA时为1V                     |

FB测试说明：

1. 需要使用10x表笔；
2. 先把基线调节到Vpp，即20V水平，能看到一个较小的负脉冲；通过调节档位到100mV放大该脉冲幅度；100mV时1格，加上10x表笔是1V，与设计和设置相符；



## 脉冲宽度测试（20260921）

之前提供的260917版本固件中脉冲宽度有问题。经检查是MCU迁移时，系统时钟没有选择25MHz HSE，而是使用了内置的16MHz HSI，这导致APBx的频率是16MHz而不是50MHz，脉冲宽度是使用TIM2的counter等待实现的，于是出现了错误，实际脉冲宽度是设定的3.125倍，即50/16。



修正：重新设置了时钟，恢复和之前一样的设置。 

- 使用HSE
- 使用/2, X8, /2的PLLM *N /R设置，System Clock Mux选择PLLCLK（Enable CSS），得到SYSCLK, HCLK, APBx PCLK都是50MHz，APBx Prescaler都设置为/1。



测试：

使用命令`set 51 200 50`，根据用户手册，测试FB，得到的脉冲宽度在640-680微秒之间，这包括有250微秒的输入电路预热（在CH0/CH1启动后的等待），然后两个200微秒脉冲和中间10微秒间隔，总计660微秒左右，和设计相符。
